# HUMAN SYSTEMS — Image Concepts (approved inventory)
Project: Soufiane Shihani personal website · https://shihanilab.github.io
Approved by Soufiane on 15 Nov 2026, with the refinements below applied.

Global photographic language: black & white, one directional key light, deep but detailed blacks, fine film grain, cinematic depth, nothing colourful. Red (#C92720) is never in the photo; it is added in code as markers and annotations.
